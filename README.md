This was the second part I scanned and 3d printed for my bike (triumph tiger 800, 2017), used 3DF zephyr this time to get the point cloud/ surface reconstruction. Worked much better than the previous COLMAP -> Meshlabs -> Meshmixer route
The initial part was acrylic that I molded into shape with a heat gun on the bike, then covered the acrylic in tape so I could get a good scan, and got my point cloud off that part. 
Printed using a bambu ps2, in ASA, 0.4 mm nozzle. Much better result that first fairing, also I was able to use sticker tape (like masking tape but with a grid pattern on it) which meant I could cover the part really fast without having to spend ages putting indiviual stickers on.
The repeating patterns on the tape didnt seem to cause any trouble for 3DF Zephyr, which I was worried it might
