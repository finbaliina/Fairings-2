This was the second part I scanned and 3d printed for my bike, used 3DF zephyr this time to get the point cloud/ surface reconstruction. Worked much better than the previous COLMAP -> Meshlabs -> Meshmixer route
The initial part was acrylic that I molded into shape with a heat gun on the bike, then covered the acrylic in tape so I could get a good scan, and got my point cloud off that part.
